# Geometry Dash — Fan Prototype

Protótipo de navegador inspirado na interface e na jogabilidade de Geometry Dash, feito com HTML, CSS e JavaScript puro.

## O que já existe
- Menu principal com botão Play central e cubo animado.
- Editor de ícone com 10 variações, cores primária/secundária e prévia.
- Skin salva no navegador com localStorage.
- Fase Spike Run: personagem corre automaticamente e precisa pular espinhos espaçados a cada 5 blocos.
- Controles por Espaço, seta para cima, clique ou toque.
- Barra de progresso, tentativas, pausa, reinício e conclusão.

## Executar
Abra `index.html` no navegador.

## Publicar com GitHub Pages
1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/ (root)**.
4. Salve e aguarde o GitHub publicar o site.

Este é um projeto de fã, não oficial, e não inclui arquivos de música, fases ou recursos proprietários do jogo original.
